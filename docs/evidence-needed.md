# Evidence Required Before Submission

The software and sample workflow can be verified without private credentials. The following claims require field evidence and must remain absent from the final results until measured.

- Exact acceptance and submission deadline
- Target-user role and consent record
- Current workflow map based on observation
- Three manual baseline timings
- Manual baseline corrections and omissions
- Ten direct-prompt baseline outputs
- Haiku and Sonnet results from the same frozen cases
- User's first unaided run time
- User edits and points of hesitation
- Day 4 feedback and the change made in response
- Final public Streamlit URL
- Final GitHub repository URL
- Final Loom URL

No document should claim a 60 percent time reduction, 95 percent grounding, 90 percent coverage, 85 percent action accuracy, or 9 of 10 passing cases until the corresponding result file exists.
