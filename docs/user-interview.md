# DeliveryBrief User Interview Guide

## Interview purpose

This interview establishes how a delivery manager currently creates a weekly client update. Ask about the most recent real report rather than an idealized process. Record only information the participant permits the project to use.

## Opening

I am studying how you prepare the weekly client update. I want to observe the actual steps, including missing information and corrections. I will anonymize any examples before using them in the assessment. You can exclude any document or detail.

## Questions

1. What caused you to start the most recent weekly update?
2. Who read it, and what did they need to decide or understand?
3. Please show me the sources you checked, in the order you checked them.
4. Which facts came directly from a source, and which required your judgment?
5. What did you need to ask another person?
6. What information was missing or contradictory?
7. Which wording could create an unwanted client commitment?
8. Who reviewed or approved the message?
9. How long did the work take from collection through approval?
10. What did you correct after the first draft?
11. What commonly causes rework?
12. What would make you refuse to use a generated report?

## Observation record

Record start and end times for collection, drafting, verification, correction, and approval. Count source switches, unsupported statements caught, missing actions, and changes before sending. Do not estimate a time when it can be measured.

## Consent and anonymization

Confirm whether the participant permits anonymized excerpts, screen captures, and timing data. Replace client, employee, repository, account, and contact names before adding any material to the repository or public application.
