# Day 1 evidence folder

Use this folder for real Day 1 proof. Do not put private client names, emails, secrets, tokens, phone numbers, or private repository links here.

## What to add today

1. Interview notes from one target user.
2. Three anonymized weekly update examples.
3. Manual timing numbers for how long the current process takes.
4. Notes on what was confusing, risky, repetitive, or slow.

## File rules

- Keep raw private material outside this repository.
- Paste only anonymized excerpts here.
- Replace real names with labels such as `Client A`, `Project X`, `Manager 1`, and `Repo A`.
- If a user gives feedback, write the exact quote only if they gave permission.
- If you are not sure something is safe to publish, leave it out and describe it generally.

## Day 1 success

Day 1 is complete when this folder contains enough evidence to answer:

- Who has this problem?
- What do they do manually today?
- How long does it take?
- What mistakes or risks happen?
- What would make DeliveryBrief useful or unacceptable?
